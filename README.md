C언어부터 시작해 C++을 공부한 지 이제 세 달이 되었습니다. 
매일 아침 눈뜨면 집을나서 도서관까지 30여 분을 도보로 이동하며, 저녁 10시까지 종일 공부에 몰두하고 있습니다. 
하루를 마치고 집으로 돌아오는 길엔 늘 스스로에게 묻습니다.
‘오늘 나는 최선을 다했는가?’
‘왜 오늘은 이것밖에 못했을까?’
‘내일은 좀 더 나아질 수 있을까?’
이런 질문들과 함께, 오늘의 공부가 실속 없었다는 아쉬움을 곱씹으며 달을 바라보며 집으로 걸어옵니다.

 국내 도서를 참고하다가 활성화된 갤러리나 카페에서 C++ 관련 질문과 답변을 찾아보기도 했지만, 제게 실질적인 도움이 되는 글을 찾기란 쉽지 않았습니다. 그러던 중, 2009년쯤 작성된 한 개발자의 글을 읽다가 비야네 스트롭스트룹(Bjarne Stroustrup)의 『The C++ Programming Language』라는 책을 알게 되었고, 그 과정에서 『Programming: Principles and Practice Using C++ (3rd Edition)』이라는 책을 발견했습니다. 현재는 이 책을 두 달 넘게 정독하며 정리하고 있습니다.
 
'어제의 자신과 비교하라'라는 조던 피터슨의 말처럼 그리고 ‘첫술에 배부르랴’라는 속담처럼, 조급함을 경계하며 내년 2월까지는 C의 기초를 탄탄히 다지는 데 집중하자는 마음으로 이 두꺼운 책을 선택했습니다. 현재 읽고 있는 책을 마치면 곧바로 『The C Programming Language』를 읽을 계획입니다. 저자가 강조한 ‘문법 사전이 되지 말라’는 조언을 마음에 새기면서도, 컴퓨터 비전공자로서 더욱 기초에 신경 써야겠다는 생각이 큽니다. 스트롭스트룹의 프로그래밍 철학과 접근 방식, 분석, 설계, 구현에 대한 고민들이 지금 제가 짊어지고 있는 학습의 무게와 깊이 있게 맞닿아 있다고 느낍니다.

C++을 처음 공부하게 된 계기는 언리얼 엔진으로 게임을 만들고 싶다는 목표와 함께, 영화 제작에도 도움이 되고 싶다는 욕심, 그리고 아두이노나 라즈베리파이를 활용해 아이디어를 직접 구현해보고 싶다는 열망 때문이었습니다. 학습 프로젝트를 진행하면서 아이디어를 구체적으로 노트에 스케치하고, 클래스 구조를 어떻게 설계할지 고민을 이어가고 있습니다. 벌써 노트 두 권이 가득 찼습니다.
이 아이디어들이 세상에 얼마나 유용할지는 모르겠지만, 언젠가 제 노트 속 낙서들이 실현되어 프로그램으로 구현되고, 직접 배포해보는 것이 저의 욕심이자 목표입니다.
